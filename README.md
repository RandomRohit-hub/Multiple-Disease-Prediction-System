# 🧠 Disease Prediction Streamlit App

This Streamlit application predicts the likelihood of three major health conditions using trained machine learning models:

- 🩸 **Diabetes**
- ❤️ **Heart Disease**
- 🧠 **Parkinson's Disease**

Each model uses a set of medically-relevant inputs to provide a simple diagnosis result, all from a single, user-friendly interface.

---

## 🚀 Features

- 📊 Easy-to-use sliders and dropdowns for input
- ⚡ Fast, real-time predictions using pre-trained models
- 🧬 Intuitive layout with side navigation
- 🌐 Works entirely in your browser with no backend needed
